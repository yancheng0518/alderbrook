# 溪畔林居 · Alderbrook

Interactive Three.js forest cottage, pavilion and creek.

Live: https://yancheng0518.github.io/alderbrook/

Run locally: `python -m http.server 4176 --bind 127.0.0.1 --directory dist`

Drag to orbit; scroll or pinch to zoom. Includes four viewpoints, time-of-day presets, independent house and oil-lamp lighting, and ambient audio.

Runtime and font license notices are included in dist/vendor and dist/fonts.
